# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-22
### Initial Release
- Initial public release of `android-ai-skills`.
- Includes the `review-pr` skill for deep auditing of GitHub PRs.
- Provides a universal toolset for Installation, Uninstallation, and Updating.
- Implements a GPG-signed manifest system for authenticity verification.
- Includes a developer test suite and a global configuration system.
